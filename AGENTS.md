# Ofertas da equipe

Para criar ou alterar ofertas no Illustrator, usar `skills/gustavo-illustrator-ofertas/SKILL.md`. Antes de compor, consultar o padrão visual e visualizar as referências pertinentes. As nove telas corrigidas pelo Gustavo prevalecem sobre posições fixas de geradores antigos; novas instruções do usuário prevalecem.

Consultar a branch aprovada antes de cada oferta, conforme a skill. Conservar a identidade visual de cada cliente. Pedir autorização antes de enviar novas ideias ou imagens à equipe; não compartilhar credenciais nem configurações locais. Revisar visualmente cada tela antes de concluir.

Se o pedido for baixar/configurar este repositório num PC novo, ler a skill e instalar o pacote: perguntar somente a versão do Illustrator se não informada, executar `Instalar.ps1`, verificar a conexão e aguardar a tarefa. Não perguntar qual oferta fazer ou arquivo abrir na instalação. Se faltar Git, instalar Git para Windows pelo mecanismo oficial disponível (por exemplo `winget install --id Git.Git -e --source winget`), dentro das permissões concedidas. Acesso privado exige login da pessoa no PC; não pedir chaves no chat. A autorização de instalação não instala ou licencia o Adobe Illustrator.

Antes de editar cada trabalho, confirmar e lembrar destino/nome/validade na primeira vez; salvar antes de editar e após cada bloco de alterações. Ao voltar ao mesmo arquivo, reutilizar os dados registrados sem repetir perguntas. A skill detalha o fluxo e contém os helpers correspondentes.
