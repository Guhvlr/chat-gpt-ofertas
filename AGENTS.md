# Ofertas da equipe

Para criar ou alterar ofertas no Illustrator, usar `skills/gustavo-illustrator-ofertas/SKILL.md`. Antes de compor, consultar o padrão visual e visualizar as referências pertinentes. As nove telas corrigidas pelo Gustavo prevalecem sobre posições fixas de geradores antigos; novas instruções do usuário prevalecem.

Consultar a branch aprovada antes de cada oferta, conforme a skill. Conservar a identidade visual de cada cliente. Pedir autorização antes de enviar novas ideias ou imagens à equipe; não compartilhar credenciais nem configurações locais. Revisar visualmente cada tela antes de concluir.

Se o pedido for baixar/configurar este repositório num PC novo, ler a skill e abrir a Central local executando `powershell.exe -NoProfile -ExecutionPolicy Bypass -File central/Abrir-Central.ps1`. A interface permite selecionar a versão do Illustrator, instalar a skill, testar a conexão e iniciar conversa. Não pedir os mesmos dados de versão no chat se a pessoa for escolher na Central. Não perguntar qual oferta fazer ou arquivo abrir na instalação. Para instalação sem interface, executar `Instalar.ps1 -VersionLabel <versao>`, usando a resposta já informada ou perguntando a versão ausente.

Apenas Illustrator está disponível na Central. After Effects, Photoshop e CapCut devem permanecer como cartões “Em breve”, sem instalação/conexão ativa, até pedido posterior do Gustavo. Não instalar essas integrações como parte deste pacote.

O repositório é público desde 04/11/2026, por autorização do Gustavo. Baixar, instalar e receber atualizações não exige login, convite, conta ou token do GitHub: não pedir esses dados a quem vai usar o pacote. Se faltar Git, instalar Git para Windows pelo mecanismo oficial disponível (por exemplo `winget install --id Git.Git -e --source winget`), dentro das permissões concedidas. Só o envio de alterações exige autenticação e permissão de escrita. A autorização de instalação não instala ou licencia o Adobe Illustrator.

Antes de editar cada trabalho, confirmar e lembrar destino/nome/validade na primeira vez; salvar antes de editar e após cada bloco de alterações. Ao voltar ao mesmo arquivo, reutilizar os dados registrados sem repetir perguntas. A skill detalha o fluxo e contém os helpers correspondentes.
